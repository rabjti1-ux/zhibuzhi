识别不到？看看收到了什么

  1. 微信：「我 → 设置 → 消息通知」里打开「通知显示消息详情」，不然通知里看不到付款内容。
  2. 支付宝：系统设置里允许支付宝发通知，支付宝自己的设置里也要打开消息通知。
  3. 付款时微信或支付宝正开在屏幕上，它们有时不弹系统通知，这种情况这里也收不到，只能手动记。
  4. 上面写「没在运行」：给「值不值」开自启动、电池设成不限制，再把权限关掉重新打开。

付款识别只看微信支付和支付宝的付款通知，内容只存在手机上。识别到可能是还款的付款时，会让你自己选择关联哪笔欠款，不会自动扣减。部分手机会限制后台运行，如果收不到提醒，在系统设置里允许「值不值」后台运行、不受电池优化限制。

导入账单或恢复备份

可以导入微信 / 支付宝账单，也可以选之前导出的备份文件（.json）恢复账目和欠款。已有的记录不会重复导入。

  1. 微信：「账单」页 → 下载账单 → 用于个人对账，账单发到邮箱。
  2. 支付宝：「账单」页右上角 → 开具交易流水证明 → 用于个人对账。
  3. 邮件里的压缩包，解压密码在微信 / 支付宝消息里。解压后选里面的 .csv 或 .xlsx。
